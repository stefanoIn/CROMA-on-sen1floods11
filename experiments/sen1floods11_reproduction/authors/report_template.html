Authors FCN predictions and CROMA

Four distributed authors checkpoints, tested with the original 4 x 256x256 inference protocol. All predictions are 512x512. Scroll horizontally to compare models; use 2x zoom to inspect boundaries. v1.0 is the reproduction; v1.1 uses the same dataset as the recorded CROMA run. RGB provides optical context and is not model input.

Masks: cyan water, dark land, grey ignored labels. Errors: cyan true water, orange false water, pink missed water. Every model uses the same raw integer-label valid mask. Original notebook metrics are separate because its label conversion mishandles ignored pixels on water-free images. Different supervision and backbones mean this comparison does not isolate decoder quality.
